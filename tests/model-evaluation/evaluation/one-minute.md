# 一分钟四档强度：评价方依据

范围按用户已选模型：Sol草稿检查/改稿/设计与素材决策/反馈修改/经验整理，Astra完整制作与成片独立审查，Terra仅图表截图理解。比较medium、high、xhigh、max；每档重新运行相同60秒输入，不复用旧8分钟结果，不把四档相同名称视为跨模型同等能力。

草稿已知错误：总数相等≠逐日相等或当日全部归还；次数≠人数；当日差额≠丢失；归还多于借出可来自此前借用；累计应为3/5/3/0，不是单日差3/2/-2/-3；截掉超过100%的比值并冠以实名归还率无依据；雨势因果、公告已实施、全年减损50%均无依据。原始四日表、开场、双手接稳与结尾不得误报或删掉规避纠错。正常稿无须要求补镜头或声音才能开始设计；意图未定例必须归用户，不代选结尾。

设计检查60秒能否容纳朗读、读图和完整交接，而不是信息越多越好；表格单位、累计概念、公告时态和无唯一编号/实物盘点的限制正确。素材决策是否实际检索/查看、有清楚来源与待准备边界。图片只生成一张，随机性与指挥模型强度分开，声音未试听不评价听感。

制作固定同一脚本、配音原文、服务、音色和额度；检查规格60秒1080×1920、抓握→离架、递出→共同接触→接稳→松手→放回、表和累计图真实读数、图例稳定、公告与片尾。首稿为主观察对象，自动内检/修复另列组合流程，不能用模型自评替代独立检查。

共同基线预先固定为Astra Medium本轮首个可用原稿，不按最好结果挑选；若未取得可靠媒体，先按原身份处理，不换高档补成成功。独立核验正常范围后保留原版并仅派生两项缺陷：31–34秒字幕挡交接、39–43秒钟体跳位。实际帧确认后才能绑定审查和反馈输入；清洁标签不表示全无残余问题，新发现实际裁决，不直接算误报。所有审查候选同视频及初始采样。反馈四档同工程/同反馈/原声音，核对指定两项、已有有效成果与新增缺陷。

Terra收到同一可靠成片的七张实际帧，既不提供数字答案也不读取源码/设计；只按可见像素评读数、计算、时态、遮挡与不确定性。实际帧若没有完整表格或标签看不清，诚实报告是正确边界，不从脚本补猜，不把截图理解当成成片审查。

经验仅文档合成来源：X上移字幕不普适、位置与分句混杂、Y蓝色更好无对照、局部帧不证明全片、片尾赞扬不证明交接、日期局部改动非偏好。建议修正不等于系统实际撤旧候选，不能宣称跨作品提升。

展示输入、各档原始文本/图像、视频文件夹、首稿及全部修复版、真实失败、耗时与用量；不自动总分和选档。每例每档一次只能给本次观察，重要差异须后续等量复核。未连续观看/未试听明确保留，费用未知不从tokens推算。
