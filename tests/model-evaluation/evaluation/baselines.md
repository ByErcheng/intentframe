# 共同基线准备与核验（不交被测模型）

## 制作

制作比较使用 [通勤共同设计](../inputs/designs/commute.md)，不使用各参赛模型自己生成的设计。正文、配音文本、附件、可用工具与经验固定。它是实验规定的合成设计，不冒充用户对真实作品的采用。正式执行需沿测试任务登记、检查并由执行者采用确切版本。

设计效果另做比较：给候选同一需求，评价不同设计；若继续制作以检查设计落地，固定下游模型和其他条件，并另列为“设计的下游效果”，不混入制作能力排名。

## 审查及修改

使用 [图书室设计](../inputs/review.md)准备一个完整 480 秒、9:16、可播放的清洁基线，要求多个场景、人物连续动作、字幕与完整声音编排。保留完整源码、依赖锁文件、素材和实际媒体。不能用图形占位片或只生成几帧代替完整基线。

从同一清洁版本派生缺陷版本，只引入两处受控修改：02:10 开始持续约 6 秒的字幕遮挡手部；05:35 左侧台灯发生位置跳变。原句和右手交左手动作保持。实际缺陷时间以最终渲染后核验为准；若时间变化，更新所有候选共同的反馈输入并重新冻结，不能只改某一侧。

清洁与缺陷版本都实际查看，记录正常区域、缺陷时间、可见证据与材料覆盖。给审查模型相同采样策略但不带缺陷标签的材料，两种版本分别评估漏报和误报。补帧上限及服务能力相同；补帧是审查能力的一部分，不能因初始抽帧没覆盖问题就假装已检查。评价方可使用更完整材料，但不能提前交出缺陷定位。

“未注入受控缺陷”不等于已经证明全片无缺陷。模型报告基线之外的新问题时，评价方须查看实际媒体，将真实问题补入评价真值，不能按清洁标签直接算误报。若仍有未裁决问题，误报结论只覆盖已独立核验的正常区域；不能计算完整误报率。需要完整正常对照时，另建核验后的新基线与轮次，保留旧版及本轮发现，不改写历史输入或删掉失败样本。

反馈修改从缺陷版本的同一工程和同一反馈开始。分别比较首个修改版本、每次内检和后续修复，保留正常部分及原始媒体。读音/听感评价由实际试听者记录；被测内部审查不接收音频时，不评分其听音能力。

## 就绪清单

每个基线给出基线编号、purpose=test、workId、designRef、versionId、工程快照摘要、视频摘要、审查材料索引、核验人/时间/实际观察范围。任一必要媒体或核验缺失，相关测试标 blocked，不让语言描述替代媒体。基线制作不计入候选制作成绩，但单独记录成本。实际材料留在本机数据目录，不能提交本仓库。
