# 案例 C：内部审查输入

本案例为虚构测试，目标作品为 8 分钟、9:16 竖屏。以执行者提供的实际共同版本、完整审查材料及其视频为检查对象；以下文字描述的是采用设计，不代表模型已经看过视频或听过声音。

一部虚构的深夜社区图书室视频。第一段交代空间和管理员；中段通过三位读者各自找到安静位置，表现同一空间适应不同需要；结尾管理员关灯前把借还记录放回抽屉。无真实人物原声，不虚构真实机构或统计数字。8 分钟内应有叙事推进、不同景别和合理留白；底部字幕与关键动作不能互相遮挡。

重要连续性：一盏暖色台灯位于画面左侧，伴随管理员出现三次；一次出现时，管理员将书从右手交到左手，再放上书架。结尾原句为“灯熄灭之前，每个人都找到了自己的位置。”不得改写。

## 固定的内容结构

- 00:00–01:00：管理员打开阅读区的灯，交代入口、书架、靠窗座位和借还台的相对位置。人物由门外进入，台灯在借还台左侧，位置建立后不随镜头切换无故翻转。
- 01:00–02:00：第一位读者背着包经过借还台，先在靠窗位置停下，再走向书架；书架没有突然变成另一个空间。管理员整理归还书籍，借还标签显示的是虚构编号，不出现真实个人信息。
- 02:00–03:00：管理员把一本蓝色封面的书从右手交到左手再上架。需要连续动作说明拿取、交接、放置，关键动作不能被字幕挡住。旁白讲“把书放回去，也把空间留出来”，不逐帧解说手的运动。近景后切回先前建立的全景。
- 03:00–04:00：第二位读者需要在纸上做笔记，将椅子轻轻拉近桌面；第一位读者正在看书，两人的动作发生在不同空间，不能把镜头剪成互相争抢同一座位。
- 04:00–05:00：第三位读者短暂停留寻找书目，管理员指向目录位置，读者自行查找。画面能辨认手势指向和目录牌；不把代为作选择表现成读者自己找到答案。
- 05:00–06:00：回到管理员与借还台，左侧台灯再次出现。以同一构图呼应开场，环境逐渐变暗，灯光作用更明显；灯的位置不随光线变化跳动。第二位读者收起笔记，第一位仍在阅读。
- 06:00–07:00：读者依次离开，不是同一角色在不同位置同时出现。空座位与有人时的布局对应，管理员整理纸条，不翻看或展示虚构读者的私人内容。
- 07:00–08:00：管理员把借还记录放回抽屉，再关灯。第三次出现台灯，先展示动作关系，再保留适当的空镜。片尾原句和虚构声明完整，声音与画面都收束，不截断台词。

全片竖屏 1080×1920，字幕需要完整信息但不持续挤占动作区域；允许合理的留白、字体和人物造型选择。书、台灯、人物服装与空间方向跨场景保持一致。审查以真实设计与媒体为准，不把风格偏好当作实现缺陷。

对照采用设计与实际审查材料，检查设计落实、可见缺陷及材料覆盖，必要时说明需要补充的时间范围。不能把未实际读取的画面说成已检查；没有实际听到声音时不能声称试听。

## 共同基线的制作约束与台词

本轮制作的是用于后续审查与反馈修改的清洁共同基线，不属于参赛模型评分。必须制作完整、可播放的 480 秒作品，不能用占位色块或长篇字幕卡替代图书室场景和人物行动。可以用代码绘制统一风格的二维人物与环境；若用生成素材，保证空间、服装、书和台灯连续。仅在有叙事意义的地方使用留白，持续通过可观察的动作和空间变化推进内容。

按以上八段的顺序使用下面台词；每段余下时间通过进出场、观察、寻找、整理与空间关系的可见变化组织。不得为了凑长度把同一个几秒循环机械重复到一分钟。逐段使用真实语音时间对齐，不猜字词时间。声音是合成叙事，不冒充真实采访。结尾先完成关灯和收束，再留下虚构声明。

```speech:library_01
晚上，街上的声音慢慢退到窗外，这间小小的图书室还亮着灯。管理员先打开阅读区，再整理借还台。门口、靠窗的座位、书架和目录，都在各自的位置上。人们暂时还没到，空间像是在等一个个不同的需要，被轻轻放进来。
```

```speech:library_02
第一位读者背着包进门。他没有马上坐下，而是先在窗边停了一会儿，再走向书架。同一个地方，有人想先看看，有人需要坐下来。管理员把归还的书分开，留出一小块可以放东西的台面，没有替谁决定今晚应该读哪一本。
```

```speech:library_03
一本蓝色封面的书，从右手交到左手，再回到书架。动作很小，却把归还的书和等待阅读的人连在了一起。放回去，不只是结束一次借阅，也让下一次寻找有了位置。没有谁催促这个动作，书架前的人也愿意稍等片刻。
```

```speech:library_04
另一位读者需要记笔记。他把椅子拉近桌边，再把纸铺平。窗边的人还在看书，两个人没有使用同一张桌子，也不需要把空间分成输赢。椅子的距离、书本的方向，还有人们放轻的动作，让不同的节奏暂时放在一起。
```

```speech:library_05
第三位读者只是短暂停留。他想找一本书，管理员指向目录，接着把选择留给他自己。目录能告诉人们去哪里找，不能代替人们决定想看什么。灯光照着桌角，也照着一张张还没有写满的纸，这一晚并不需要相同的答案。
```

```speech:library_06
再回到借还台，窗外已经更暗。左侧那盏台灯还在原处，只是此刻显得更暖。有人收起笔记，有人还在阅读。管理员把纸条理齐，把走动经过的地方留空。安静不是所有人都不动，而是每个人的动作，都给别人留下一点余地。
```

```speech:library_07
人们陆续离开，椅子回到桌边，窗边的位置空了下来。白天没有发生什么大事，今晚也没有谁突然明白全部道理。有的人找到需要的书，有的人只是有了一段能坐下来的时间。读过的纸页、还回的书，留下可以被下一次继续使用的秩序。
```

```speech:library_08
管理员最后检查借还记录，把它放回抽屉。门外还有街灯，屋里可以暂时暗下来。这不是一个替所有人安排好生活的地方，只是一段共同使用的时间，被仔细地收好，留给下一次开门。灯熄灭之前，每个人都找到了自己的位置。
```
