# 制作共同设计：距离与到达时间

这是合成测试指定的设计，供制作能力比较；不代表真实作品已经获用户采用。执行者按测试流程登记和检查本设计，所有制作候选使用同一正文。480 秒、1080×1920、30 fps；片尾合成数据声明；甲为蓝色实线加圆形标记，乙为橙色虚线加三角标记，全片固定。颜色不是唯一识别方式。画面上方留信息标题，中部呈现地图或关系，下方字幕保持距底边至少 140 像素；必要时分屏而非缩小到不可读。

## 固定资料

甲路线 6 千米，乙 4.5 千米；五天总分钟：甲 31/33/32/35/34，乙 30/29/43/31/32。总时间包含步行、等待和换乘。两者平均 33，甲中位数 33，乙中位数 31。周三乙错过换乘；没有可靠分项分钟、全年统计、费用或无障碍数据。公告仅为下月拟将乙班次间隔从 7 分钟改为 5 分钟，实施未确认。

## 00:00–00:45 疑问

画面从人物步行进入两条抽象路线，短路线先亮起，随后出现同一终点。时钟指针与路线长度并非同步变化。最后停在问题上，不提前给路线贴胜负标签。人物仅为几何虚构角色，不用真实城市照片。

```speech:s01
你有没有遇到过这样的早晨：地图上选了更短的路，到了公司，却发现自己并没有更早。我们很容易把距离当作时间的答案。但从家门到目的地，中间还夹着等车、换乘，还有每一天不完全一样的情况。今天，用两条虚构路线和五天合成记录，看看一段路的时间，究竟是怎样形成的。
```

## 00:45–01:45 路线

甲乙并排示意：步行到站、车程、甲直达与乙换乘、终点步行。只写提供的全程公里数；分项不标伪造分钟。逐步突出两者的结构差异。持续标注“路线示意，非实际导航”。

```speech:s02
从青桥附近到南园办公室，甲路线大约六千米，公交直达。乙路线大约四点五千米，需要在地铁里换乘。乙的距离少了四分之一，但这还不能告诉我们，它的总时间是不是也少四分之一。走到车站、站台上等待、途中换乘、出站后的步行，都属于这次通勤。图上的线只是结构示意，不是按真实街道绘制的导航。
```

## 01:45–02:45 五天记录

每次出现一行，读数时对应行高亮，周三先正常出现再重点解释。最后五行和单位同时可读，单位“分钟”、范围“本案例五天总耗时”持续可见；不能删除 43 或让坐标截断隐藏它。

```speech:s03
先看完整记录。甲在五天里分别用了三十一、三十三、三十二、三十五和三十四分钟。乙分别是三十、二十九、四十三、三十一和三十二分钟。这里每一个数字，都是从出发到到达的总时间。周三，乙错过一次换乘，最终花了四十三分钟。这四十三分钟已经包括等待，不能再把等待加上一次。
```

## 02:45–03:45 相同平均与不同波动

用可核算的累加过程显示各为 165÷5=33。再展示点图，连线只用于引导阅读，不暗示时间趋势必然延续。突出甲范围 31–35、乙 29–43；范围不是概率。给观众读图时间时让图上阅读指引继续推进。

```speech:s04
把五天加起来，两条路线都是一百六十五分钟，平均每天三十三分钟。可是，平均一样，并不代表每天一样。甲的几个点比较接近；乙有几天更快，也有一天明显更久。平均数帮助我们概括，但也会压缩差别。看一条路线时，我们还需要看看数字怎样分布，而不是只留下一个平均值。
```

## 03:45–04:40 一次错过怎样产生影响

用两个时间轴展示“赶上”和“错过”的概念过程，均标“概念示意，非实测分项”。不添加未知的每段分钟。切回周三总时长时移除示意轴，避免观众误以为它来自真实拆分数据。

```speech:s05
换乘把行程接成了几个部分。前一段稍慢一点，可能刚好错过下一班，也可能并没有影响。我们用动画说明这种关系，但这里没有每一段实测了几分钟的资料，不能把示意变成精确测量。能确定的只有：在这份合成记录里，周三的乙错过了换乘，总时间是四十三分钟。它解释了一个案例，不能替所有通勤下结论。
```

## 04:40–05:30 感受与记录

人物气泡说“每次都等十分钟”，再把气泡与“个人感受”标签绑定；旁边是五天记录，两者不融合成同一统计图。人物不是被嘲笑的对象，表情只表现疲倦。

```speech:s06
角色抱怨，每次换乘都要等十分钟。这样的感受可能来自几次印象深刻的经历，我们可以理解它。但一句抱怨还不是完整记录，也不能直接变成每次都发生的事实。感受告诉我们哪里让人在意，记录则帮助我们检查它发生过多少次、在什么条件下发生。两种信息都有价值，回答的却不是同一个问题。
```

## 05:30–06:25 尚未实施的公告

公告原意展示“下月拟调整”“实施日期待正式公告”。7→5 表示班次间隔的计划变化，旁边另画乘客到站时刻，不显示“人人省2分钟”。保留未实施状态到这一段结束。

```speech:s07
再看一则计划中的公告：下月，乙线高峰班次间隔拟从七分钟调整到五分钟，实施日期还要等正式公告。首先，它还不是已经发生的变化。其次，班次间隔与每个人的等待时间不同。你到站的时刻、是否赶上下一班，都可能改变实际等待。因此，不能把间隔少两分钟，直接说成人人提前两分钟到达。
```

## 06:25–07:20 决策条件

三张条件卡依次出现：对到达时间的要求、换乘偏好、步行和设施条件。已知的五天表与未知条件用不同区域表示。任何“全年概率”或无障碍路线排名都不出现。

```speech:s08
如果明天有一个不能迟到的约定，你可能更在意波动。如果你不喜欢换乘，直达的体验也有意义。步行和站内设施同样可能重要，但这份资料没有提供它们的完整条件。五天记录太少，无法估计全年迟到概率。一次最快或最慢，也不是永远如此。作决定之前，要先问自己在意什么，再核对资料有没有回答那个问题。
```

## 07:20–08:00 回到开头

重现两条路线，保留两种标记，地图退为背景。总结卡依次点出距离、总时间、波动与条件。最后 5 秒保留声明和结尾，不突然截断人声。

```speech:s09
这次比较并没有选出一条适合所有人的路线。它只是把一个容易混在一起的问题拆开：距离是距离，总时间包含沿途发生的事，几天的观察也有自己的范围。下一次面对一个看起来更短的选项，我们可以先多看一眼它需要经过哪些环节。距离告诉你走了多远，时间还取决于途中发生了什么。
```

## 素材、声音与允许变化

配音台词原文固定，按实际语音时间安排字幕和动作，不猜字词边界。窗口时长是内容编排目标；不得裁掉话音，必要时在同一内容段内调整图形推进与停留，保证整片 480 秒。可在不改变事实、指标、配色标识和段落顺序的前提下选择字体、人物造型和转场。环境/交通音不是必需；如使用不得压住旁白。音乐由可用能力和本轮预算决定，不因未配置音乐服务阻塞无音乐版本。素材来源记录随实际选择保存。
