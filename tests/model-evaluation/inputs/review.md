# 案例 C：内部审查输入

本案例为虚构测试，目标作品为 8 分钟、9:16 竖屏。以执行者提供的实际共同版本、完整审查材料及其视频为检查对象；以下文字描述的是采用设计，不代表模型已经看过视频或听过声音。

一部虚构的深夜社区图书室视频。第一段交代空间和管理员；中段通过三位读者各自找到安静位置，表现同一空间适应不同需要；结尾管理员关灯前把借还记录放回抽屉。无真实人物原声，不虚构真实机构或统计数字。8 分钟内应有叙事推进、不同景别和合理留白；底部字幕与关键动作不能互相遮挡。

重要连续性：一盏暖色台灯位于画面左侧，伴随管理员出现三次；一次出现时，管理员将书从右手交到左手，再放上书架。结尾原句为“灯熄灭之前，每个人都找到了自己的位置。”不得改写。

## 固定的内容结构

- 00:00–01:00：管理员打开阅读区的灯，交代入口、书架、靠窗座位和借还台的相对位置。人物由门外进入，台灯在借还台左侧，位置建立后不随镜头切换无故翻转。
- 01:00–02:00：第一位读者背着包经过借还台，先在靠窗位置停下，再走向书架；书架没有突然变成另一个空间。管理员整理归还书籍，借还标签显示的是虚构编号，不出现真实个人信息。
- 02:00–03:00：管理员把一本蓝色封面的书从右手交到左手再上架。需要连续动作说明拿取、交接、放置，关键动作不能被字幕挡住。旁白讲“把书放回去，也把空间留出来”，不逐帧解说手的运动。近景后切回先前建立的全景。
- 03:00–04:00：第二位读者需要在纸上做笔记，将椅子轻轻拉近桌面；第一位读者正在看书，两人的动作发生在不同空间，不能把镜头剪成互相争抢同一座位。
- 04:00–05:00：第三位读者短暂停留寻找书目，管理员指向目录位置，读者自行查找。画面能辨认手势指向和目录牌；不把代为作选择表现成读者自己找到答案。
- 05:00–06:00：回到管理员与借还台，左侧台灯再次出现。以同一构图呼应开场，环境逐渐变暗，灯光作用更明显；灯的位置不随光线变化跳动。第二位读者收起笔记，第一位仍在阅读。
- 06:00–07:00：读者依次离开，不是同一角色在不同位置同时出现。空座位与有人时的布局对应，管理员整理纸条，不翻看或展示虚构读者的私人内容。
- 07:00–08:00：管理员把借还记录放回抽屉，再关灯。第三次出现台灯，先展示动作关系，再保留适当的空镜。片尾原句和虚构声明完整，声音与画面都收束，不截断台词。

全片竖屏 1080×1920，字幕需要完整信息但不持续挤占动作区域；允许合理的留白、字体和人物造型选择。书、台灯、人物服装与空间方向跨场景保持一致。审查以真实设计与媒体为准，不把风格偏好当作实现缺陷。

对照采用设计与实际审查材料，检查设计落实、可见缺陷及材料覆盖，必要时说明需要补充的时间范围。不能把未实际读取的画面说成已检查；没有实际听到声音时不能声称试听。
