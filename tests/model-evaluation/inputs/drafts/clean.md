# 草稿检查 B3：雨天公交

目标作品为 8 分钟、9:16 竖屏，虚构叙事。这是内容草稿，镜头与声音的细节仍留给设计阶段。

用户原始要求：重点是陌生人之间细小的互相照顾。保留结尾原句“雨停以后，我们各自向前。”不引入事故、冲突或真实当事人的身份信息。其他视觉、声音和镜头处理由项目自主设计。

待检查草稿：故事依次发生在车站、车内、下车后。车站里，乘客把滴水的一面转向自己，给旁边的人留出空间。车内，另一位乘客提醒即将下车的人拿好手套。接近终点时，窗外的雨变小。下车后，他们各自走向不同方向。三段可以通过伞和窗外光线串联，让观众在日常细节中理解互相照顾。结尾旁白：“雨停以后，我们各自向前。”
