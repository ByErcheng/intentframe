# 一分钟雨伞站：设计采用后的素材准备

目标60秒1080×1920竖屏，虚构社区雨伞站，暖灰背景二维插画，值守者绿衣、访客黄衣，同一把蓝色折叠伞。动作需要借伞和双手接稳归还；参考图不直接等于可用动画。

核对能力与来源，实际检索本机声音，选择并导入一个适用于雨天入口的候选。仅据名称/分类初选，不试听，不声称雨声、音量或情绪已经适用，沿用现有本机使用声明和署名要求。

仅用项目工具生成一张原创参考设定图：两位不同成人、同一把蓝色折叠伞及伞架，人物与物件分离排列，不出现文字、台词、真实品牌或机构标识；同一张图不要画多个不同结构的伞作为同一物件。实际打开原图，检查人数、伞柄/腕带结构、手部遮挡和后续分层条件。只能生成一次，不满意也保留并指出，不换编号重试。只有方图时说明如何作为竖屏造型参考，不冒称已经裁切、分层或完成1分钟视频。保存原图、声音文件、来源和使用安排。
