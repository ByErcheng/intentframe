# 一分钟正常草稿对照

原始要求：虚构雨天的共享伞站，60秒竖屏，主题是先看记录再下判断。三段依次是入口借伞、核对记录、交还伞；保留原句“看清流转，再谈损耗。”不暗示真实采访，不添加未经提供的数据。镜头、具体造型、转场和声音由设计阶段安排。

待检查草稿：访客伸手前先停一下，值守者指向登记处。登记完成后访客拿起蓝色折叠伞。中段暂不下损耗结论，而是提醒观众区分借出、归还和此前未还。另一位访客将一把蓝色折叠伞交给值守者，接稳后放回架子。结尾“看清流转，再谈损耗。”片尾注明“本片人物与故事为虚构”。

这还是内容草稿，没有制作镜头、声音或成片；本轮检查它是否违背已有要求，不把尚待设计的细节当成前置缺口。
