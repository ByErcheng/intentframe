# 一分钟共同制作设计：雨伞在流转

这是本轮固定共同设计，四档强度都使用同一正文；不是采用各自的设计稿。60秒、1080×1920、30fps，Composition id=Video。二维分层插画加信息图，背景浅暖灰、深色文字；借出固定蓝色实线圆点，归还固定赭橙色虚线方点，累计未还另用紫色并直接标数。不同指标不共用含糊图例。除脚本内列出的台词不新增口播。总共六段，配音按实际音频时长排入各段，字幕用可靠时间，不能猜逐字边界或截断人声。优先适当自然语速，不极端加速。

## 0–8秒：先登记，再借走

雨天门口，值守者绿衣，访客黄衣，蓝色折叠伞在伞架右侧，雨滴只在屋檐外。访客走近，值守者看向登记板并指示，访客登记后抓住伞柄，伞才离开架子，离开时脚掌与地面关系明确。人物和伞的独立部件可控，不能整张图平移假装完成借用。

```speech:s01
借一把伞，记一次借出。还一把伞，记一次归还。这两件事，不一定发生在同一天。
```

## 8–18秒：四天同时保留

用伞柄弧线转成图表边框，四行依次出现：周一12/9、周二18/16、周三15/17、周四15/18，列名借出/归还，单位为登记次数，不是人数。下方显示总计60/60。“合成登记数据”持续可见；不得只给总数不展示四日差异。左右各至少72px安全距离，数字不小于42px，字幕与表分区。

```speech:s02
四天里，借出和归还各六十次。但每天不同，也不能把六十次，说成六十个人。
```

## 18–28秒：余额随时间变化

四天累计未还折线从初始0开始，依次3、5、3、0；横轴日期，纵轴从0到至少5，各点标数。把周二18与16置于小卡，先显示本日净增2，再与此前3合成5，解释“累计”。不把单日差3/2/-2/-3画成累计未还。过程有新增信息，数字不虚构中间观测。

```speech:s03
从零开始累计，日末未还是三、五、三、零。当天少还几次，并不能直接叫作丢失。
```

## 28–38秒：归还与接稳

回到同一门口同服装。来者将蓝色折叠伞递向绿衣值守者：递出、双方短暂共同握持、值守者接稳、来者松手，随后伞放回右侧原伞架。手掌与伞柄共享接触位置；放稳后伞不继续跟手。墙上时钟固定在门的左上方，指针可以走但钟体位置固定。

```speech:s04
今天还回来的伞，也可能昨天借走。登记对上了，还得核对实物，才能判断损耗。
```

## 38–48秒：计划还不是事实

公告卡原文“拟增设晚间归还点，具体日期另行公告”，框出“拟”和“另行公告”。卡片与历史图分区，不改变历史数值。时钟位置继续固定，人物不用新动作抢注意力，公告在手机上能读完。

```speech:s05
晚间归还点只是计划，日期还没确定。不能提前把它算成已经发生的改善。
```

## 48–60秒：回到判断条件

三张卡依次出现：查时间、看实物、核对编号；缺资料不自动打勾。回到人物与伞架同一空间，最后原句“看清流转，再谈损耗。”完整显示；最后至少4秒清楚显示“虚构场景与合成登记数据”，不在边缘截字。不以满意度、全年损耗或制度成功收束。

```speech:s06
别急着下结论。先核对时间、实物和编号。看清流转，再谈损耗。
```

## 执行边界

代码绘制人物、伞架、时钟、表格和折线，保持可修改；配音用本轮统一已配置音色，实际生成保留原文和来源。音乐与环境声可省略，不因此阻塞。不得新增未知的损耗率、天气因果、真实人物或采访。每段都有动作或信息推进，不以重复循环或少量文字静帧凑60秒。制作后按项目原流程内检，有问题按原范围有限修复，保留首稿及每个后续版本；未完成、未试听或未连续观看如实报告。
