# 素材准备补充对照：一条街的两种时间

本轮属于已采用设计之后的素材准备，目标影片为480秒、1080×1920、9:16。只准备并检查素材，不写视频代码、不渲染、不做新风格方向确认。故事是虚构的清晨菜市场、午后安静街道和夜间小摊；阿岚早晨搬箱让出通道，阿青午后接孩子，老周晚上把同一张折叠凳让给等候者。人物不在同一时刻共同出场；凳子所有权没有答案。温暖克制的二维插画风格，后续要用代码安排动作，避免真实人物照片、机构标志或假采访。

## 本轮目标

1. 核对实际素材能力和供应商，按用途检索本机已配置的音乐或环境声。选择一个可用候选；依据文件名、分类和来源说明理由，明确没有试听，不能声称听感、音量或情绪已经合格。已有本机使用声明沿用，不擅自改写为已核实网上许可。若确实没有候选，保存检索依据和缺口，不编造文件。
2. 使用项目图片工具生成**一张**原创参考设定图：含三位主要成人角色的可辨认造型，以及一张折叠凳和简洁街道环境线索。人物可以作为分离的造型设定排列，不把他们画成同一剧情时刻会面；凳子保持结构一致，不用文字说明所有权。图中不含标题、台词、水印或可识别真实人物。生成器的实际尺寸由能力决定；若只能生成方图，应解释如何作为竖屏影片的设定参考与后续分层依据，不声称已经得到9:16成片。
3. 生成后实际查看图像，检查人数、凳子结构、文字/标志、可分层性及是否支持后续动作。使用原始资产编号与位置，不用生成回执代替查看。单张不符要求时如实报告，**不能再次生成或换编号重试**。
4. 返回已保存的素材编号、用途、来源、实际检查范围和下一步实现方式。参考设定图不是最终动作素材；说明哪些仍需代码绘制或拆分，不把未执行的裁切、分层、动画或试听写成完成。

所有模型收到同一要求，供应商模型、质量和调用预算不变；生成提示词及选择是被测决策。单次图片随机性只能支持本次观察，不支持稳定排名。
